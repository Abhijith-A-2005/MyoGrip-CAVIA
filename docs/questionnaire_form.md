CAVIA Post-Condition Questionnaire
Confirm the study protocol with the project guide before collecting responses. Use anonymous participant identifiers.
NASA-TLX (raw)
Rate each scale from 0–100 in increments of 5. For Performance, 0 = perfect and 100 = failure.
- Mental demand
- Physical demand
- Temporal demand
- Performance
- Effort
- Frustration
Raw score: mean of the six scales.
System Usability Scale (SUS)
Use the standard SUS wording and a 1–5 scale: strongly disagree to strongly agree.
1. I think that I would like to use this system frequently.
2. I found the system unnecessarily complex.
3. I thought the system was easy to use.
4. I think that I would need the support of a technical person to be able to use this system.
5. I found the various functions in this system were well integrated.
6. I thought there was too much inconsistency in this system.
7. I would imagine that most people would learn to use this system very quickly.
8. I found the system very cumbersome to use.
9. I felt very confident using the system.
10. I needed to learn a lot of things before I could get going with this system.
Scoring: odd items subtract 1; even items subtract the response from 5. Sum adjusted scores and multiply by 2.5.
Perceived control (1–7)
1. I felt in control of which grip the hand used.
2. The system never chose a grip I did not intend.
3. I could easily override the suggestions when I wanted something else.
4. The suggestions felt like help, not like decisions made for me.
Score: mean of four items.
Confidence (1–7)
1. I was confident the grip I confirmed was the right one.
2. I trusted the system's suggestions.
3. I would feel confident using this system for daily tasks.
Score: mean of three items.
End-of-session
- Rank the conditions by preference.
- What was easiest?
- What was most frustrating?
- Did anything feel out of your control?
